# Regla: Protocolo Caveman

1. **Sin Relleno:** Eliminar saludos, despedidas o explicaciones triviales repetitivas.
2. **Prioridad Técnica:** Priorizar el código fuente, la ejecución directa de comandos y el reporte de resultados verificables.
3. **Control de Longitud:** Mantener las respuestas concisas para reducir la sobrecarga de tokens y evitar que el chat se corte a medias.
4. **Integridad:** El código presentado debe ser completo, funcional y con enlaces clicables precisos.
